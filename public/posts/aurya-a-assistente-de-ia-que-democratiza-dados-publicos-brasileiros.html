Athena: a assistente de IA que democratiza dados públicos brasileiros

2026-06-05

Imagine poder perguntar — em linguagem natural — quantas escolas existem em seu município, qual a taxa de internação por dengue no DF, ou como o Censo 2022 impactou sua região. Essa é a proposta da Athena, a assistente de Inteligência Artificial desenvolvida pelo DataIESB.

O que é a Athena

A Athena é um chatbot inteligente que conecta o usuário a bases de dados públicas brasileiras. Por meio de processamento de linguagem natural alimentado por modelos de IA da Amazon Bedrock, ela interpreta perguntas do dia a dia e retorna respostas estruturadas com dados oficiais.

Bases de dados disponíveis

A assistente atualmente opera sobre quatro grandes domínios:

  • Educação — Censo Escolar, ENEM, dados do Ensino Superior
  • Saúde — SUS, Autorizações de Internação Hospitalar (AIH), dados ambulatoriais
  • Demografia — IBGE, Censo 2022, indicadores populacionais
  • Segurança — Dados de trânsito e ocorrências

Como funciona

O usuário seleciona um tema e faz uma pergunta. A Athena usa IA generativa para entender a intenção, consulta as bases de dados armazenadas no data lake do DataIESB (infraestrutura AWS com Athena e S3) e retorna a resposta com visualizações e métricas relevantes.

Tecnologia por trás

A arquitetura combina:

  • Amazon Bedrock — Modelos de linguagem para interpretação e geração de respostas
  • AWS Athena — Consultas SQL sobre dados no data lake
  • Amazon S3 — Armazenamento do data lake com dados públicos processados
  • Interface conversacional — Frontend interativo com visualização de nós temáticos

Acesso gratuito

A Athena está disponível gratuitamente para qualquer pessoa em athena.dataiesb.com. Não é necessário cadastro — basta acessar, escolher um tema e perguntar.

Impacto

A ferramenta democratiza o acesso a dados que antes exigiam conhecimento técnico em consultas SQL ou navegação por portais governamentais complexos. Estudantes, pesquisadores, jornalistas e gestores públicos podem obter respostas imediatas sobre a realidade brasileira.

Desenvolvida inteiramente pelo DataIESB com patrocínio da Amazon Web Services.
